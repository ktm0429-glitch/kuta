## 接客力向上トレーニングアプリ

アルバイトスタッフが勤務時間外に取り組む、遊技延長につながる会話力・接客力向上のための
研修アプリです。研修(場面設定に沿った選択式の問題)を最後まで完了すると1ptが付与されます。
全店舗のスタッフを「店舗 + フルネーム」で登録・管理し、誰が今何ポイント持っているかを
**Googleスプレッドシート上でそのまま**確認できます。

### 全体の仕組み(かんたんな説明)

- スタッフが触る「画面」と、ポイントを記録する「台帳」は別の場所にあります。
- 台帳の役割をしているのが **Googleスプレッドシート** です。ポイントの記録・確認は
  すべてこのスプレッドシートを直接見れば分かります。管理者用の特別な画面はありません。
- 画面(スタッフが実際に触るページ)は、御社の既存のホームページのフォルダに
  アップロードして使います。

```
[スタッフのスマホ] → (画面: app/dist を自社サイトにアップロード)
                          ↓ 通信
                    [Google Apps Script] → [Googleスプレッドシート(台帳)]
```

### 構成

- `app/` : スタッフ用フロントエンド(Vite + React + TypeScript)
  - `/` ログイン(店舗はプルダウンから選択、お名前(フルネーム)を入力するとその場で登録される)。
    **登録は初回のみ**。一度登録すると、その端末のブラウザに情報が保存され、次回以降は
    ログイン画面を出さずに研修メニューへ直接進む(別のスマホ・別のブラウザでは再登録が必要)
  - `app/src/config.ts` : **ここにApps ScriptのURLを1つ貼り付けるだけ**でよい設定ファイル
  - `app/src/data/stores.ts` : 店舗マスタ(店舗ID・店舗名の一覧)
  - `app/src/data/questionBank.ts` : **研修問題本体(現在21問)**。新しい問題は
    ファイル内のコメントの手順に従ってオブジェクトを1件追加するだけでよい
  - `app/src/data/trainingContent.ts` : 年代別モジュールの定義(タイトル・概要・冒頭の解説のみ)
  - `/modules` 研修メニュー(年代別: 20代 / 30〜50代 / 60〜70代)、保有ポイント表示
  - `/training/:moduleId` 研修本編(遊技延長につながる場面設定 + 選択式の問題)
  - `/admin/login`, `/admin` 管理ダッシュボード(全店舗のポイント一覧・CSV出力。
    スプレッドシートを直接見れば十分な場合は使わなくてもよい)
- `apps-script/Code.gs` : **バックエンド本体**。Googleスプレッドシートの
  「拡張機能 → Apps Script」に貼り付けて使う1ファイルのプログラム。
  スタッフ登録・研修完了時の採点とポイント付与・二重付与防止・管理者向けの
  ポイント一覧取得や手動調整を行う

### なぜこの構成か(設計メモ)

- 当初はFirebase(Google製の別クラウドサービス)を使う構成も検討しましたが、
  「専務や店舗責任者が使い慣れたスプレッドシートでそのままポイントを確認したい」
  という要望に合わせて、Googleスプレッドシート + Apps Script(スプレッドシートに
  紐づく無料のプログラム実行環境)による構成に変更しました。専用の管理画面を
  覚えなくても、スプレッドシートを開くだけで済みます。
- ポイントの不正付与を防ぐため、問題の採点とポイント加算は必ず `apps-script/Code.gs`
  側で行い、スプレッドシートの中身をアプリから直接書き換えることはできません。
- 同じ研修を何度実行してもポイントが増えないよう、「完了記録」シートで
  完了済みかどうかを判定してから加算しています。同時アクセスによる書き込み
  competing を避けるため `LockService`(処理の順番待ち)も使っています。
- スタッフのログインは店舗選択+フルネーム入力のみの簡易方式です(社員番号のような
  IDは求めない設計)。同姓同名のスタッフが同じ店舗にいる場合、現状は同一人物として
  扱われます。表記ゆれ(ニックネーム表記など)がある場合もポイントが別々に記録される
  ため、スタッフには毎回同じ表記のフルネームを入力してもらう運用にしてください。
- 研修問題(`app/src/data/questionBank.ts`)はサンプル/たたき台です。「傾聴」「雑談の
  FORDの法則(Family/Occupation/Recreation/Dreams)」「クッション言葉」「高齢者との
  コミュニケーションの基本」など、一般的に知られている接客・コミュニケーション手法を
  基にしています。実際の接客方針に合わせて店舗側・専務側で文言を調整してください。
  正解は `apps-script/Code.gs` 内の `ANSWER_KEY_ENTRIES` にサーバー側の正として
  重複管理しているため、問題を追加・変更した場合は両方を更新し、Apps Scriptを
  再デプロイしてください(下記「研修問題を追加・変更したいとき」を参照)。
- 問題の正解は、押しつけがましい引き止めではなく気配り・情報提供による自然な
  会話延長を選ぶ内容にしています。無理な引き止めや、困っているお客様に付け込む
  ような文言にならないよう、コンテンツを追加・変更する際もこの方針を維持してください。

### セットアップ手順(はじめての方向け)

#### 1. 台帳(Googleスプレッドシート + Apps Script)を用意する

1. [Googleスプレッドシート](https://sheets.google.com/) を開き、空白のスプレッドシートを新規作成する
2. 分かりやすいように、スプレッドシートの名前を「接客研修 台帳」などに変更する(任意)
3. 上部メニューの「**拡張機能**」→「**Apps Script**」をクリックする(別タブでエディタが開く)
4. エディタに最初から入っているコード(`function myFunction() {...}` など)を全部選択して削除する
5. このリポジトリの `apps-script/Code.gs` の中身を全部コピーして、エディタに貼り付ける
6. 貼り付けたコードの上の方にある
   ```
   var ADMIN_KEY = 'CHANGE_ME_TO_YOUR_OWN_SECRET';
   ```
   の `CHANGE_ME_TO_YOUR_OWN_SECRET` の部分を、好きな文字列(合言葉)に書き換える
   (これが管理者用のパスワードになります。他人に推測されにくいものにしてください)
7. キーボードで保存する(Windowsは `Ctrl+S`、Macは `Cmd+S`)
8. 右上の「**デプロイ**」ボタン→「**新しいデプロイ**」をクリックする
9. 「種類の選択」の歯車アイコンをクリックし、「**ウェブアプリ**」を選ぶ
10. 「次のユーザーとして実行」は **自分** のまま、「アクセスできるユーザー」は **全員** にする
11. 「**デプロイ**」ボタンをクリックする
12. 初回は「このアプリは確認されていません」という警告画面が出ることがあります。
    これは自分で作ったプログラムだから出る一般的な確認です。「詳細」→
    「(プロジェクト名)に移動」→「許可」と進んで問題ありません
13. 発行された「**ウェブアプリのURL**」(`https://script.google.com/macros/s/.../exec` の形)
    をコピーする(あとで使います)

#### 2. 画面(フロントエンド)を用意する

1. `app/src/config.ts` を開き、
   ```ts
   export const API_URL = 'PASTE_YOUR_APPS_SCRIPT_WEB_APP_URL_HERE'
   ```
   の部分を、手順1-13でコピーしたURLに書き換えて保存する
2. 依存パッケージのインストール
   ```
   cd app && npm install
   ```
3. ビルド(画面一式のファイルを作る)
   ```
   npm run build
   ```
   実行すると `app/dist` フォルダの中に、アップロードすべきファイル一式ができる
4. `app/dist` フォルダの中身(`index.html` や `assets` フォルダなど)一式を、
   FTPやレンタルサーバーのファイルマネージャーを使って、自社ホームページの
   公開フォルダの中に作った任意のフォルダ(例: `public_html/training/`)に
   そのままアップロードする
5. `https://自社ドメイン/training/` にアクセスして、ログイン画面が表示されれば成功

### 動作確認・使い方

- **スタッフ用画面**: `https://自社ドメイン/training/`
- **管理ダッシュボード(任意)**: `https://自社ドメイン/training/#/admin/login`
  (手順1-6で決めた合言葉でログイン)
- **ポイントの確認**: 手順1で作ったGoogleスプレッドシートを開き、「スタッフ」という
  シートを見れば、店舗・氏名・ポイントの一覧がそのまま確認できます
  (研修が1つも終わっていなくても、ログインした時点で0ptの行が追加されます)
- 研修が完了すると「完了記録」シートに、景品交換などでポイントを手動で減らすと
  「ポイント調整履歴」シートに、それぞれ自動で記録が追加されます

### 研修問題を追加・変更したいとき

1. `app/src/data/questionBank.ts` を開き、ファイル末尾のコメントにあるテンプレートを
   コピーして、新しい問題を1件追加する
2. `apps-script/Code.gs` の `ANSWER_KEY_ENTRIES` にも、同じ `id`・`ageBand`・正解の
   選択肢ID(`correctChoiceId`)を1行追加する
3. Apps Scriptのエディタに戻り、`ANSWER_KEY_ENTRIES` を書き換えて保存する
4. 「デプロイ」→「デプロイを管理」→ 編集(鉛筆アイコン)→ バージョン「新バージョン」→
   「デプロイ」をクリックする(**これをしないと、スプレッドシート側の変更が
   反映されません**。URLは変わらないので、画面側の設定を変える必要はありません)
5. 画面側は `cd app && npm run build` を再実行し、できた `app/dist` の中身を
   ホームページに再アップロードする
