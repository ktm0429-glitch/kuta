# NotebookLM連携セットアップ用プロンプト（安全版・手順5.5削除済み）

PCのClaude Code（ローカル実行）に、下の枠内をそのまま貼る。

```
【Claude Code × NotebookLM 連携セットアップ(安全版)】
これから、あなた(Claude Code)とNotebookLMを連携させます。以下を順番に進めてください。各手順の前に、何を実行するかを1行で説明してから実行してください。

1. インストール
・まず uv が入っているか確認してください。無ければ、公式の導入方法を1つずつ案内してください。
・インストールの前に、PyPIの「notebooklm-mcp-cli」のプロジェクトページを確認し、ソースのリンク先が GitHub の jacob-bd/gemini-notebook-mcp-cli であることを私に見せてください。違っていたら、そこで止めてください。
・確認できたら `uv tool install notebooklm-mcp-cli` でインストールしてください。pip3 でシステムのPythonに直接入れないでください。

2. ログイン
・ログインに使うのは、NotebookLM専用のサブのGoogleアカウントです。メインのGmailは使いません。`nlm login` の前に「サブアカウントでログインしますか」と私に確認し、私がOKと言ってから実行してください。
・ブラウザが開いたら、Googleへのログインは私が自分でやります。パスワードや確認コードは絶対に聞かないでください。

3. 認証の確認と保護
・`nlm login --check` で認証を確認してください。表示されたメールアドレスがサブアカウントであることを、私に確認させてください。
・続けて `nlm auth storage set protected` を実行し、ログイン情報を暗号化して保存させてください。保護が有効になったことも確認してください。
・最後に、ノートブックの一覧を見せてください。

4. 動作テスト
・「セットアップテスト」という名前のノートブックを新しく作ってください。
・ソースに入れる公開WebページのURLを、私に1つ聞いてください。
・追加できたら内容について1つ質問し、出典付きの回答が返ることを確認してください。

5. ルールの追記
ユーザー全体のCLAUDE.md(~/.claude/CLAUDE.md、無ければ作成)に、次の内容を追記してください。追記する前に、全文を私に見せてOKをもらってください。
・NotebookLMに送ってよいのは、私が明示的に指示した公開資料(論文、Webページ、動画、書籍の抜粋など)だけ。EAのソースコード、バックテスト結果、取引履歴、口座に関する情報は、絶対にNotebookLMへ送らない。
・NotebookLMの回答は「資料にそう書いてある」ことを示すだけで、内容の検証ではない。資料に出てくる数値(勝率、PF、シャープレシオなど)は、すべて「仮説:」として扱う。自分で再計算するまでは、判断の根拠にしない。
・調べ物や分析をしたら、結果を ~/リサーチ/ に「YYYY-MM-DD_テーマ名.md」の名前で保存する。gitリポジトリの中には保存しない。

6. 完了報告
全部終わったら「連携完了」と報告し、次の2つを3行以内でまとめてください。
・今日からできるようになったこと
・送ってはいけないもの

途中で詰まったら、エラー文をそのまま見せて、次に何をすればいいかを1つずつ教えてください。
```
