## 1. なぜ短期か（問題認識）

GOLDは「方向は合っているのに、途中の上下で削られる」銘柄。H4/D1のトレンドを長く持つと、
1日に数十ドル単位の振れに SL を狩られるか、含み益を吐き出す。

Blitz はこれを逆手に取る：

| 課題 | Blitzの対策 |
|---|---|
| 大きいSLで長く持つと削られる | M5執行・SLは直近構造＋小バッファ（0.6〜2.0 ATR） |
| 含み益を吐き出す | **1R到達で50%利確＋建値+0.1Rロック**、以降ATRトレール |
| 伸びない玉がジワジワ負ける | **タイムストップ**：12本(1時間)で+0.3R未満なら撤退 |
| 急変動・指標スパイク | 指標前後30分停止＋5分前全決済、スパイク足後3本待機 |
| 持ち越しギャップ | GMT 20:00 全決済、金曜は19:00 |
| アジア時間の薄い値動き | **アジア時間は取引しない**（ブレイクアウトも使わない） |

## 2. 2つのエンジン

### エンジンA: Liquidity Sweep Reversal（ストップ狩りの逆張り）
GOLDの一番の特徴は「直近高値/安値の少し上/下にあるストップを刈ってから戻る」動き。
これを確定足で捉える。

- **流動性レベル**：直近3時間(36本)の未タッチ高値/安値（最低4本前に形成）＋ 前日高値/安値（本日未到達のもの）
- **条件（売りの例）**
  1. 足の高値がレベルを 0.05〜0.8 ATR 突き抜ける（0.8超は本物のブレイクとして見送り）
  2. 終値がレベルの**内側**に戻る
  3. 上ヒゲが値幅の45%以上、終値が足の下半分
  4. 値幅が0.8 ATR以上（意味のある狩り）
  5. M15が強トレンド（ADX≥35）で上方向なら逆張りしない
- **SL**：ヒゲ先 + 0.15 ATR（+スプレッド）
- **リスク倍率**：M15バイアス順行=1.0 / 中立=0.8 / 逆行=0.5、前日高安スイープは+0.2

### エンジンB: Trend Pullback（トレンド中の押し目・戻り）
M15がトレンド（ADX≥22、EMA50の上で上向き）かつH1 EMA200と同方向のときのみ。

- M5 EMA21 に直近3本以内でタッチ（±0.15 ATR）
- RSI(7) が押し目中に45以下（売りは55以上）＝本当に押している
- 確定足が陽線・実体40%以上・高値圏引け・前足高値を終値で超える
- 終値がEMA21から1 ATR以上離れていたら追わない
- **SL**：直近3本の安値 − 0.2 ATR

### 優先順位
トレンド局面（ADX≥22）→ Pullback優先、なければSweep。
レンジ局面 → Sweep優先。

## 3. エグジット

1. SL / 最終TP = 2.5R（ブローカー側に置く）
2. **+1R**：SLを建値+0.1Rへ → 成功後に50%部分決済
3. 以降 ATR×1.0 トレール
4. **タイムストップ**：12本でTP1未到達かつ+0.3R未満 → 撤退
5. 最大保有48本（4時間）
6. 逆シグナル発生で決済
7. 指標5分前、GMT20:00、金曜19:00 で全決済

## 4. 資金管理・安全装置

- 1トレード 0.5%リスク（Equity基準、SL距離から自動ロット）
- 最小ロットでも想定リスク1.5倍超なら見送り
- 日次 −2% / +4% で当日停止、1日最大6回、3連敗で停止
- 負け後3本クールダウン
- スプレッド > 35 points 見送り
- ATR(14)/ATR(100) が 0.7〜2.5 の範囲外は見送り（閑散・暴走回避）
- 同時保有は1ポジションのみ

## 6. 検証手順（重要）

> この環境ではMT5を動かせないため、**まだバックテストしていない**。
> 以下の手順で検証してから実運用すること。

1. **コンパイル**：MetaEditor で `kutaGOLD_Blitz.mq5` をコンパイル（警告ゼロ確認）
2. **バックテスト**：XAUUSD / M5 / *Every tick based on real ticks* / 直近2年
3. **エンジン別評価**：`InpUseSweep` と `InpUsePullback` を片方ずつOFFにして、各エンジン単体で期待値プラスか確認。マイナスのエンジンは切る
4. **最適化**（過剰最適化を避けるため少数パラメータのみ）
   - `InpSweepLookback` 24〜60
   - `InpSweepMaxPierce` 0.5〜1.2
   - `InpTP1R` 0.8〜1.5 / `InpTP2R` 2.0〜3.5
   - `InpTimeStopBars` 6〜24
5. **ウォークフォワード**：前半18ヶ月で最適化 → 後半6ヶ月でOOS確認。OOSでPF 1.2未満なら不採用
6. **デモ4週間** → 最小ロットでリアル
