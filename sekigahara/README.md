# 関ヶ原立体絵図 — Sekigahara in 3D

慶長五年九月十五日（1600年10月21日）の関ヶ原の合戦を、テレビ特番の俯瞰CG図として
再現したブラウザ単体の3Dビジュアライゼーション。`index.html` 一枚で動きます。

## 収録内容

| | |
|---|---|
| 地形 | 笹尾山・天満山・松尾山・南宮山・桃配山・伊吹山地などを標高値から生成した高さ場。相川／藤古川と、中山道・北国街道・伊勢街道を地表に沿って描画 |
| 軍勢 | 東西44隊。兵力に応じた隊形ブロックと、家紋・姓を刷った幟。石田の大一大万大吉、島津の丸十字、井伊の井桁、毛利の一文字三星など8家は紋を描画 |
| 進軍矢印 | 曲線に沿ってテーパーする帯。山形（シェブロン）が進行方向へ流れ、章の進行に合わせて描き足される。退却は中抜き、不戦は破線 |
| 霧 | 朝霧（多層のドリフトする霧面）＋指数フォグ＋交戦地点から立ちのぼる硝煙と発砲炎 |
| カメラ | 全8章を貫く1本のCatmull-Romスプラインによるクレーン移動。ドラッグ・ホイールでいつでも手動操作に切り替わる |

## 八章立て

`07:45 布陣` → `08:00 開戦` → `08:30 激突` → `11:00 不動（南宮山）` →
`11:45 催促（問鉄砲）` → `12:00 裏切（小早川）` → `12:30 崩壊` → `14:00 退口（島津）`

時刻は現代時刻と十二時辰（辰の刻／巳の刻／午の刻／未の刻）の両方で表示されます。

## 操作

- `Space` 再生・停止 / `←` `→` 章送り
- 帯のドラッグでスクラブ、章名をクリックでその章の頭へ
- 画面をドラッグすると自動カメラを離れて自由視点（ホイールで寄る、Shift+ドラッグで平行移動）
- 右の「表示」パネルで 霧・進軍矢印・部隊名・地名・自動カメラ を個別に切り替え

## 実装

three.js r160 の UMD ビルドを CDN から読むだけで、ほかに依存はありません。
地形・家紋・霧・煙のテクスチャはすべて実行時に生成しています。
ブラウザで `index.html` を開くか、任意の静的サーバーに置いてください。

## 出典としての注意

布陣座標・兵力・時刻は通説（江戸期以来の布陣図と『関原軍記大成』系の記述）に基づく
概数です。近年の研究では開戦時刻や小早川の動いた時刻に異説があり、
本図はあくまで通説を可視化したものです。
